# Lab 01 - Building a Virtual Cybersecurity Lab

## Objective

Build a virtual cybersecurity lab for learning network security, vulnerability assessment, and Security Operations Center (SOC) concepts using Oracle VirtualBox.

## Lab Environment

| Component | Purpose |
|-----------|---------|
| Oracle VirtualBox | Virtualization Platform |
| Ubuntu Desktop | Security Workstation |
| Metasploitable 2 | Vulnerable Target Machine |
| Windows | Windows Security Labs |

## Skills Practiced

- Virtual machine creation
- Virtual networking
- Static IP configuration
- Internal Network configuration
- NAT networking
- Basic troubleshooting
