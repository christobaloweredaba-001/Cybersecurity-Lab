# Lab 01 - Building the Virtual Cybersecurity Lab

## Objective

Build a virtual cybersecurity lab using Oracle VirtualBox to practice networking, system administration, vulnerability assessment, and defensive security concepts.


## Lab Environment

| Component | Purpose |
|-----------|---------|
| Oracle VirtualBox | Virtualization Platform |
| Ubuntu Desktop | Analyst Workstation |
| Metasploitable 2 | Vulnerable Target |
| Windows VM | Windows Security Labs |

---

## Skills Practiced

- Virtual machine deployment
- Virtual networking
- Network troubleshooting
- Static IP configuration
- Internal Network configuration
